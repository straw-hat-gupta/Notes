# Monitoring

[[Projects & Learning/HomeLab/HomeLab Overview|HomeLab]] · [[Projects & Learning/Big Tasks|Big Tasks]]

## Outcome

Preserve the desired cluster monitoring and benchmark features in one place. These were recorded as ideas; their current implementation has not been verified.

## Requirements captured

- One screen showing load on every node: CPU and memory, plus GPU utilization on pve-d1.
- Show CPU, GPU, and other available sensor temperatures.
- Be able to run simple benchmarks from a button, including network speed and CPU-style benchmarks.
- Consider scheduled simple benchmarks with saved results and a history view, such as network-speed trends.
