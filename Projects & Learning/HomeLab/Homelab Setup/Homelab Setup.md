# Homelab Setup

[[Projects & Learning/HomeLab/HomeLab Overview|HomeLab]] · [[Projects & Learning/Big Tasks|Big Tasks]]

## Outcome

Keep the authoritative record of the homelab's current hardware, configuration, workloads, and operational status. Update the affected setup records whenever confirmed facts change.

## Inventory

[[Projects & Learning/HomeLab/Homelab Setup/Node Inventory|Node Inventory]] contains the existing hardware table. Treat it as documented hardware until verified on the machines.

## Setup records

Node Inventory is the existing node and workload record. Add focused RAM, storage, network, software/configuration, or health notes here when there is enough confirmed detail to warrant them, and link them from this overview. Keep one authoritative record for each fact; mark unknown, historical, conflicting, and unverified details clearly.

Follow [[Projects & Learning/HomeLab/AGENTS|the HomeLab agent instructions]] when maintaining these records.
